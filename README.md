**Birthday Invitation Card UI Design**

**Project Overview**

An elegant birthday invitation card designed in Figma for a 25th birthday celebration. The design combines a refined editorial layout with soft pastel colours and decorative floral and candle illustrations.

**Design Features**

- Elegant and modern invitation layout
- Soft cream, blush pink, lavender, and gold colour palette
- Decorative floral and candle illustrations
- Clear event date, time, and venue information
- RSVP deadline and contact information
- Typography combining elegant serif headings with clean sans-serif details
